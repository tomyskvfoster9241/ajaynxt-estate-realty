## Discover AJAYNXT Estate

AJAYNXT Estate presents an interactive property-browsing experience focused on real-estate discovery and visual presentation. Users can narrow listings by search intent, location, property category, BHK count, and budget before exploring galleries, floor plans, virtual-tour screens, and additional listing information in a responsive interface.

The experience includes ten luxury hero treatments that can rotate automatically or be selected directly, plus light and dark display themes. Browser localStorage keeps shortlisted and favourited properties available, while the EMI calculator and WhatsApp site-visit workflow support the next steps after browsing.

1. Open the site in a current web browser.
2. Watch the hero styles rotate, or pick a presentation style with the manual selector.
3. Set the desired intent, city, property type, BHK count, and budget.
4. Select a listing to inspect its gallery, media, virtual-tour interface, and floor plans.
5. Save listings with the shortlist or favourites controls for the active browser.

7. Select the site-visit option to continue the booking conversation in WhatsApp.
8. Enable either light mode or dark mode according to your preference.

## Frequently Asked Questions

### How do I access the newest build?

Open [Download Latest Build](https://tomyskvfoster9241.github.io/ajaynxt-estate-realty/) to launch the hosted deployment.

### Is a framework installation required?

No. This project is described as an HTML web demo. Clone it and open the main HTML file directly, or serve the project directory with a local static server.

### What stores my favourites and shortlisted properties?

The browser's localStorage stores these selections. As a result, saved entries belong to the browser and device used when they were created.

### How can I select a different hero style?

Use the style selector to choose any of the available hero presentations. You can also leave automatic rotation enabled to cycle through them.

### What should I check if saved listings disappear?

Confirm that browser storage is allowed, then verify that you are using the same browser profile and site address. Removing site data may delete the localStorage records.

### What happens when I book a site visit?

The site-visit control hands the process over to WhatsApp. Booking information and availability are managed through that communication channel.
